# Contributing

Suggestions and code improvements are welcome through GitHub issues or pull requests.

Before opening a pull request:

1. run `python -m unittest discover -s tests -v`;
2. run `python scripts/audit_public_release.py`;
3. confirm that no video, participant photograph, consent/recruitment file, calibration artefact, local path, or unreviewed result is included;
4. explain any change to processing parameters in the changelog.

Please do not upload new human-subject data to this repository. Contact the maintainer before proposing a change to the public data boundary.
