# Responsible disclosure

If you find a privacy issue, an accidental recording, or a direct identifier in the public repository, do not open an issue with the material attached. Contact [fabian.nana@pucp.edu.pe](mailto:fabian.nana@pucp.edu.pe) with the file path and a short description so the release can be reviewed and withdrawn safely.

Please do not attempt to identify the coded records in `data/` or combine them with external datasets. Source videos and consent-controlled files are not distributed through this repository.
