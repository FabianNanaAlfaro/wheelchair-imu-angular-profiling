# Public data card

## Scope

The public release contains two data components already prepared for this project:

| Path | Description | Public boundary |
| --- | --- | --- |
| `data/iSen/` | De-identified iSen CSV exports organised by coded trial folders. | Signal exports only; no video or direct identifiers. |
| `data/profiling_data.xlsx` | De-identified support workbook with participant codes, review sheets, and derived summaries. | No names, contact details, consent forms, or source recordings. |

The `examples/synthetic/` files are generated demonstration material and are not derived from any participant.

## Not included

The following remain in the restricted project store and are intentionally absent from GitHub:

- source videos and exported video formats;
- camera frames with unnecessary identifying context;
- signed consent documents, recruitment posters, phone numbers, and QR codes;
- calibration files, local path manifests, and unreleased intermediate outputs;
- any file that could be used to reconnect a code to a person.

## Reuse guidance

The public iSen files and workbook should be treated as de-identified research support materials, not as a medical dataset or a clinical product. Do not attempt re-identification, link the codes to other datasets, or publish a new derivative that adds identifying information.

The MIT license covers the code and documentation. Data reuse remains subject to the permissions and conditions under which the research materials were prepared.

## Video requests

For a legitimate method-review request involving source video, contact [fabian.nana@pucp.edu.pe](mailto:fabian.nana@pucp.edu.pe). Requests are evaluated by the research team and are not fulfilled by sharing a public download link.
