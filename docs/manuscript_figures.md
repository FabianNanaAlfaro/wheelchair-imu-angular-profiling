# Manuscript figures

The public figure generator is a downstream analysis step. It reads the verified participant-level excursion table, computes the supported statistics, and writes publication-ready figures without modifying the source data.

## Supported figures

Figure 5 displays all ten participant observations for the five angular-excursion variables and marks the cohort median. Figure 6 computes the exploratory Spearman rank-correlation matrix from the same participant-by-variable table. Both figures use the canonical order defined in [`../scripts/manuscript_variables.py`](../scripts/manuscript_variables.py).

Run the complete generation and validation command from the repository root:

```powershell
python -m pip install -r requirements.txt
python scripts\generate_manuscript_figures.py --check --publish-assets
```

Generated working copies are written to `outputs/manuscript_figures/`. Stable publication assets are written to [`../assets/manuscript/`](../assets/manuscript/). The figure manifest records the repository version, commit, input hash, variable order, participant count, and the supported figure set without storing local filesystem paths.

## Public boundary

The public analytical layer contains the participant-level excursion values and cycle-count traceability. It does not contain participant mean normalized profiles or individual retained-cycle identifiers. Therefore Figures 2–4 are not generated by this repository, and the public documentation does not claim that those profile plots can be reconstructed from the available numerical files.

## Figure interpretation

The angular quantities are manufacturer-defined iSen descriptors. They are reported as device-defined outputs and should not be interpreted as independently calibrated anatomical joint angles. Figure 6 is descriptive and exploratory; its coefficients do not establish causation or clinical validity.
