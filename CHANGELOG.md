# Changelog

- reorganized the public repository around the general de-identified iSen database;
- separated the manuscript-related analytical configuration from the public reference implementation; and
- removed the optional acquisition-support layer from the public tree to keep the repository scope focused.

## [1.1.2] — 2026-09-05

- clarified the distinction between the manuscript-related analysis and the public reference implementation;
- added a dedicated description of the manuscript-related processing and statistical configuration; and
- expanded the code guide and public reproducibility scope.

## [1.1.1] — 2026-09-02

- refined the repository presentation around the general iSen database;
- clarified the separation between the database layer and the manuscript-related analysis; and
- kept the iSen CSV exports, support workbook, and derived public data unchanged.

## [1.1.0] — 2026-09-02

This version introduced the public reference implementation and expanded the protocol documentation.

- added a tested Python reference pipeline with a deterministic synthetic demo;
- documented the filtering, derivatives, phase normalization, and public data boundary;
- clarified that iSen provides the primary quantitative angular descriptors;
- added a public-release audit and continuous integration checks;
- kept the de-identified iSen exports and support workbook already released with the repository;
- documented that restricted acquisition records, recruitment/consent material, and calibration files are not distributed.

## [1.0.0] — 2026

- initial public repository release with cleaned MATLAB/Python code and de-identified support materials.
